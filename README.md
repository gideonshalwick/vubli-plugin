# Vubli plugin

Connect Vubli to plan content and manage social posts from your AI assistant. Find saved ideas, refine scripts, prepare drafts, and schedule or publish uploaded videos to connected social accounts when requested. Features depend on your Vubli plan, team role and approved permissions. A Vubli account is required.

## Connect

Install this plugin in a compatible Cursor plugin host. Complete the OAuth sign-in with your Vubli account and review the requested permissions. No API key or client secret is included or required in this package.

Start by asking: "List my Vubli brands and ask which brand I want to work with."

For a brief connection test, list brands, then create and read back a disposable draft in a test brand. Verify it in Vubli. Do not publish test content.

You can revoke the connection in Vubli under Connections.

## Package contents

This repository contains only the plugin manifest, public MCP connection configuration, logo and these instructions. The Vubli app and hosted backend source are not distributed here. The hosted service authenticates users and enforces account permissions.
